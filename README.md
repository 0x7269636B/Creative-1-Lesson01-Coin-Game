# Creative 1 — Lesson 01 Coin Game

Σταθερό template για Pygame + pygbag σε GitHub Codespaces.

## Για τους μαθητές

1. Άνοιξε το Codespace.
2. Περίμενε να ολοκληρωθεί το αρχικό setup.
3. Δούλεψε στο `main.py`.
4. Τρέξε:

```bash
bash tools/run-game
```

5. Άνοιξε το **Port 8000** από το tab **Ports**.

Για τερματισμό πάτησε **Ctrl+C**.

> Μην κάνεις `pip install`, `pip install -U` και μην αλλάζεις τα αρχεία `.devcontainer/`, `requirements.txt` ή `tools/` χωρίς οδηγία.
